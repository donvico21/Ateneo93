## Sections

- **Hero** — full-screen banner with batch identity
- **About** — batch history and Jesuit mission
- **Events** — reunions and upcoming batch activities
- **Gallery** — photo archive (add images directly to the grid in `index.html`)
- **Connect** — contact form and social links

## Deploying to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Set source to **Deploy from a branch** → `main` → `/ (root)`.
4. Save — the site will be live at the URL shown in Pages settings within a minute.

## Customizing

- **Events** — edit the `.event-card` blocks in `index.html` with real dates and details.
- **Gallery** — replace the placeholder `<div class="gallery-item">` slots with `<img>` tags pointing to your photos.
- **Social links** — update the `href="#"` values in the Connect section with real Facebook group, Discord, or email links.
- **Sections/Names** — the contact form dropdown lists section names; update the `<option>` values to match the actual Batch '93 sections.
